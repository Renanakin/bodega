# Seeds

Datos base para ambientes locales y de prueba.

## Estado al 17-03-2026

Ya existe una semilla minima del MVP en `0001_inventory_mvp_seed.sql`. Su objetivo es facilitar validacion local del flujo base de inventario.

## Semillas minimas recomendadas para el MVP

- una bodega central de ejemplo
- uno o dos productos de ejemplo
- opcionalmente un movimiento de entrada inicial para pruebas locales

## Regla

Las semillas no reemplazan pruebas ni migraciones. Solo deben facilitar arranque local y validacion manual.
