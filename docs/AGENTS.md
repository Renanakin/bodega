# AGENTS

## Folder

`docs`

## Objetivo

Mantener la documentacion funcional, tecnica y operativa del sistema multi-bodega.

## Skills del area

- redactar requerimientos funcionales y no funcionales
- documentar arquitectura y decisiones tecnicas
- mantener runbooks de operacion y despliegue
- traducir reglas de negocio a especificaciones claras

## Agente ideal

- perfil analista funcional
- perfil arquitecto de software
- perfil documentador tecnico

## Plugins recomendados

- markdownlint
- Markdown All in One
- JSON

## Reglas

- no documentar funcionalidades no implementadas sin marcarlas como futuras
- toda decision tecnica relevante debe quedar en `architecture/`
- toda operacion manual sensible debe quedar en `operations/`
