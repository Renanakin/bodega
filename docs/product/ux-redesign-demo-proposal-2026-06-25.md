# UX Redesign Lead - Propuesta de mejora demo

## Objetivo

Hacer que la demo venda mejor en menos de 2 minutos, reduciendo exploracion innecesaria y reforzando la historia comercial.

## Diagnostico

### Lo que hoy funciona bien

- dashboard con narrativa comercial
- transferencias con estados visibles
- exportes operativos
- auditoria como cierre de confianza

### Lo que aun puede mejorar

- exceso de opciones laterales para una demo
- modulos secundarios compiten con los modulos fuertes
- falta una capa de “presentacion ejecutiva” para decisores

## Propuesta UX

### 1. Activar un modo presentacion

- simplificar sidebar a:
  - dashboard
  - inventario
  - transferencias
  - reportes
  - auditoria
- esconder `chat`, `slotting` y `reposicion` en modo demo

### 2. Reforzar jerarquia del dashboard

- primer bloque:
  - alertas
  - backlog
  - cierres
- segundo bloque:
  - recorrido sugerido
  - valor del producto
- tercer bloque:
  - actividad e incidencias

### 3. Hacer mas ejecutiva la lectura de reportes

- renombrar bloques a lenguaje de negocio:
  - “Riesgos de abastecimiento”
  - “Backlog interno”
  - “Trazabilidad por SKU”
- destacar botones de exporte con promesa concreta:
  - “Exportar inventario para cliente”
  - “Exportar backlog para seguimiento”

### 4. Mejorar transferencias como escena principal

- separar visualmente:
  - pendiente de aprobacion
  - en transito
  - recepcion parcial
  - cerrada
- convertir incidencias en tarjetas o tags mas visibles

### 5. Mejorar auditoria como escena de confianza

- mostrar usuario responsable con nombre amigable
- resaltar que toda accion queda registrada
- agregar una leyenda corta:
  - “Cada cambio relevante queda auditado automaticamente”

## Microcopys sugeridos

- cambiar “Cobertura demo” por “Escenario listo para presentacion”
- cambiar “Solicitudes pendientes” por “Pedidos internos por resolver”
- cambiar “Transferencias recibidas” por “Reposiciones completadas”
- cambiar “Exportar historial” por “Descargar trazabilidad”

## Prioridad de implementacion

1. modo presentacion
2. sidebar reducida para demo
3. copy ejecutivo de dashboard y reportes
4. visual mas fuerte para incidencias
5. auditoria enriquecida con nombre humano
